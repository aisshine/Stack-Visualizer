4. Description of the Program

The Stack Visualizer is a Java application that demonstrates how a stack data structure works through a graphical user interface (GUI). It allows users to perform stack operations and visualize the elements in the stack.

5. Features

The program has six main operations. Push adds an element to the top of the stack, while Pop removes the top element. Peek displays the top element without removing it, and Clear removes all elements from the stack. 
Check Stack shows the current stack information, while Random generates random elements and adds them to the stack.

6. Requirements
   
The program requires the Java Development Kit (JDK) to compile and run the application, a Java-compatible IDE or compiler for development,
and a computer running Windows, macOS, or Linux

8. How to Run the Program
 
To run the program, first download or clone the repository and open the Java files in a Java-compatible IDE, such as Apache NetBeans. Make sure all required Java files are in the correct location,
then compile the source code and run the main class, StackVisualizer.java, which contains the main() method

9. Stack Implementation

The program uses the Last In, First Out (LIFO) principle. This means the last element added to the stack is the first element removed. The stack implementation manages elements and supports operations such as push, pop, and peek.
